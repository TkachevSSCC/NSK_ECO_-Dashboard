# Комплект ЕСПД

**Программное средство:** «NSK Eco Dashboard» (рабочее наименование: `nsk_eco`).
**Назначение:** мониторинг и моделирование работы сети экологических станций в Новосибирске.
**Версия комплекта:** 1.0.
**Состояние:** проект документации; реквизиты утверждения, организации и разработчика подлежат заполнению.

Документы подготовлены по структуре стандартов ЕСПД (ГОСТ 19). Markdown-версия предназначена для сопровождения в репозитории; перед официальным выпуском следует перенести материалы в утверждённый организацией шаблон с титульными листами, листами утверждения и обозначениями документов.

## Принятые ограничения

- Документация отражает состояние исходного кода на дату подготовки комплекта; интерфейсы и функции могут изменяться.
- Программное средство содержит моделируемые сценарии загрязнения и сетевого обмена. Его показатели не следует трактовать как сертифицированные измерения атмосферного воздуха.
- Параметры аппаратной платформы, точности исходных измерений, аттестованных методик и целевых эксплуатационных показателей в проекте не заданы.
- Перед промышленным применением заказчик и разработчик должны согласовать требования к защите, резервному копированию, доступности, нагрузке и хранению данных.
